¿Qué es Linux Mint?

Linux Mint es una distribución de Linux basada en la comunidad basada en Debian y Ubuntu que se esfuerza por ser un "sistema operativo moderno, elegante y cómodo que sea potente y fácil de usar". Linux Mint proporciona una completa box multimedia incluye un software propietario y viene con una variedad de aplicaciones gratuitas y de código abierto. El proyecto fue concebido por Clément Lefèbvre y está siendo desarrollado activamente por el equipo de Linux Mint y la comunidad.

Requisitos del sistema para la instalación del sistema operativo

  • Procesador x86
  • Memoria RAM 1 GB (se recomiendan 2 GBs para un rendimiento más fluido)
  • 15 GBs de espacio en disco (se recomiendan 20 GBs)
  • Tarjeta gráfica 1024x768

Para conseguir una experiencia aún más óptima, sus desarrolladores sugieren un procesador más moderno y al menos 4 GB de RAM. Por otro lado, antes de instalar Linux Mint, es aconsejable hacer una copia de seguridad de tus datos importantes y asegurarte de que tu PC pueda arrancar desde un USB o un DVD.

Proceso de preparación del medio de instalación (USB, DVD)

Requisitos Previos

  1. Unidad USB (8 GB mínimo, se recomiendan 16 GB).
  2. Archivo ISO de Linux Mint.

Descargar ISO

Crear el medio de instalación:

  • Descarga Rufus (es la herramienta que nos servirá para bootear nuestra USB).

Descargar Rufus

  1. Conecta la USB y selecciona el archivo ISO de Linux Mint.
  2. Configura la unidad y haz clic en "Empezar" para iniciar la creación del medio.

Finalización y prueba:

  1. Expulsa la unidad USB de manera segura.
  2. Reinicia la computadora y arranca desde la USB para comenzar la instalación de Linux Mint.

Pasos para acceder al menú de arranque y seleccionar el medio de instalación

  • Conecta la unidad USB que contiene el medio de instalación a la computadora.

Entrar al BIOS/UEFI:

  • Reinicia la computadora y presiona repetidamente la tecla Esc, F2, F10, F12 o Del (dependiendo del fabricante de tu computadora) para entrar al BIOS/UEFI.

Menú de Arranque:

  • Si tu BIOS tiene un menú de arranque rápido, presiona la tecla correspondiente (generalmente F12 o Esc) para acceder directamente al menú de arranque y seleccionar la unidad USB.

Cambiar el Orden de Arranque:

Si necesitas cambiar el orden de arranque:

  • Ve a la sección de arranque o "Boot".
  • Establece la unidad USB como la primera opción.
  • Guarda los cambios y sal del BIOS/UEFI (generalmente con F10).

Arrancar desde el Medio:

  • Una vez guardados los cambios, la computadora reiniciará y comenzará a cargar desde la unidad USB, listo para iniciar el proceso de instalación de Linux Mint.

Opciones de Particionamiento del disco duro durante la instalación

El proceso de particionamiento en Linux Mint es similar al de Ubuntu, ofreciendo las mismas opciones:

Instalación Normal:

Proporciona una configuración automática de particiones sugerida por Linux Mint. Apropiado si deseas una instalación sencilla sin personalización detallada.

Personalizado (Avanzado):

Permite crear y gestionar particiones manualmente, también puedes establecer particiones separadas para / (raíz), /home, y swap (opcional). Ideal si prefieres una configuración específica de particiones según tus necesidades.

Configuración de ajustes básicos como idioma, huso horario y teclado

Idioma

  1. Abrir Configuración del Sistema: Ve a "Configuración del Sistema".
  2. Soporte de Idiomas: Selecciona esta opción.
  3. Instalar/Eliminar Idiomas: Haz clic en "Instalar/Eliminar Idiomas" y selecciona el idioma deseado. Asegúrate de que el paquete de idioma esté completamente instalado.

Huso Horario

  1. Abrir Configuración del Sistema: Ve al menú de inicio y selecciona "Configuración del Sistema".
  2. Fecha y Hora: Selecciona esta opción.
  3. Huso Horario: Selecciona la pestaña "Fecha y Hora", haz clic en "Cambiar" en la sección de huso horario y selecciona el huso horario deseado. Aplica los cambios.

Teclado

  1. Abrir Configuración del Sistema: Ve al menú de inicio y selecciona "Configuración del Sistema".
  2. Teclado: Selecciona esta opción.
  3. Distribuciones: Ve a la pestaña "Distribuciones", haz clic en "Añadir" y selecciona la distribución de teclado deseada. Aplica los cambios y cierra la configuración.

Instalación de drivers necesarios para el funcionamiento del sistema operativo

Actualización del Sistema

Actualiza tu sistema para asegurar que tienes los últimos paquetes y mejoras.

  • sudo apt update
  • sudo apt upgrade

Instalación de Controladores Adicionales

Abre el menú. Ve a "Administración" > "Administración de controladores". Selecciona los controladores que necesitas y sigue las instrucciones en pantalla.

Reiniciar el Sistema

Reinicia tu computadora para que los nuevos controladores se apliquen correctamente.

  • sudo reboot

Creación de cuentas de usuario y configuración de contraseñas

Añadir y crear usuarios es esencial para los administradores. El comando "useradd" permite crear nuevos usuarios especificando opciones como el directorio de inicio y el shell por defecto. Para una interfaz más interactiva, se puede usar "adduser", que guía al administrador a través del proceso de configuración del usuario, incluyendo la asignación de una contraseña. Tras crear un usuario, el comando "passwd nombre_usuario" se usa para establecer una contraseña segura. Estos pasos aseguran que los usuarios estén configurados correctamente y cumplan con las políticas de seguridad del sistema.

Actualización del sistema operativo después de la instalación

Conéctate al servidor usando SSH:

ssh usuario@direccion_ip

Actualiza la lista de paquetes disponibles:

sudo apt update

Actualiza todos los paquetes instalados a sus versiones más recientes:

sudo apt upgrade -y

Si quieres actualizar a una nueva versión de Linux Mint, puedes hacerlo con:

sudo apt dist-upgrade -y

Limpia el sistema eliminando paquetes obsoletos y dependencias no utilizadas:

sudo apt autoremove -y

sudo apt autoclean

Reinicia el servidor (si es necesario):

sudo reboot

Configuración de opciones de seguridad y privacidad

  • Firewall (UFW): Esencial para controlar el tráfico de red. UFW ofrece una configuración sencilla y efectiva para limitar accesos no autorizados.
  • SELinux: Ofrece un control avanzado sobre los permisos y accesos, ideal para entornos que requieren una seguridad muy rigurosa y granular.
  • Actualizaciones de seguridad: Mantener el sistema actualizado es fundamental para protegerse contra vulnerabilidades conocidas.

Resolución de problemas comunes durante la instalación

    Errores de particionamiento

  • Crear o modificar particiones: Usa GParted para gestionar particiones.
  • "No root file system is defined": Durante la instalación, asegúrate de asignar / como punto de montaje para la partición raíz.

    • Fallos en la instalación de controladores

  • Controladores de gráficos: Utiliza el Gestor de controladores o, si no puedes iniciar, usa nomodeset en GRUB.

    • Dispositivos de red no funcionan

  • Actualizar kernel: Ejecuta sudo apt update, upgrade, e instala el kernel adecuado.

    • Otros problemas comunes

  • Sistema no arranca: Arranca desde un Live USB y repara GRUB.
  • Falta de espacio en disco: Usa GParted para liberar espacio antes de la instalación.
  • Instalación se cuelga: Verifica la integridad del medio de instalación y usa opciones de arranque correctas desde el Live USB.

Recomendaciones y mejores prácticas para la instalación del Sistema Operativo

  • Verifica Compatibilidad: Asegúrate de que el hardware sea compatible con el sistema operativo.
  • Respaldo de Datos: Haz una copia de seguridad de tus datos importantes antes de instalar.
  • Medio de Instalación Seguro: Usa medios de instalación oficiales y verificados.
  • Particionamiento: Planifica cómo dividir tu disco de manera efectiva.
  • Instala Actualizaciones: Actualiza el sistema y los controladores una vez instalado.
  • Documentación: Registra ajustes y problemas para referencia futura.
