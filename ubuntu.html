¿Qué es Ubuntu?

Ubuntu es una distribución GNU/Linux que ofrece un interesante sistema operativo para equipos de escritorio y servidores en el ámbito educativo. Es una distribución basada en Debian cuyas principales características son: facilidad de manejo, actualizaciones frecuentes, facilidad de instalación del sistema, búsqueda e instalación de programas robusta y fácil al basarse en paquetes, libertad de uso y distribución.

Requisitos del sistema para la instalación del sistema operativo

  • Procesador de doble núcleo a 2 GHz o superior
  • Al menos 4 GB de RAM
  • 25 GB de espacio libre en disco
  • Puerto USB y una memoria USB con al menos 4 GB de capacidad
  • Conexión a Internet

Ten en cuenta que estos métodos de instalación sólo funcionan con ordenadores y no se adaptan a los usuarios de VPS, ya que estamos instalando Ubuntu con una interfaz gráfica. Si prefieres una interfaz de línea de comandos, considera mejor comprar un hosting VPS.

Proceso de preparación del medio de instalación (USB, DVD)

Requisitos Previos

  1. Unidad USB (8 GB mínimo, se recomiendan 16 GB).
  2. Archivo ISO de Ubuntu.

Descargar ISO

Crear el medio de instalación:

  • Usa Rufus (es la herramienta que nos servirá para bootear nuestra USB).

Descargar Rufus

  1. Conecta la USB y selecciona el archivo ISO de Ubuntu.
  2. Configura la unidad y haz clic en "Empezar" para iniciar la creación del medio.

Finalización y prueba:

  1. Expulsa la unidad USB de manera segura.
  2. Reinicia la computadora y arranca desde la USB para comenzar la instalación de Ubuntu.

Pasos para acceder al menú de arranque y seleccionar el medio de instalación

  • Conecta la unidad USB que contiene el medio de instalación a la computadora.

Entrar al BIOS/UEFI:

  • Reinicia la computadora y presiona repetidamente la tecla Esc, F2, F10, F12 o Del (dependiendo del fabricante de tu computadora) para entrar al BIOS/UEFI.

Menú de Arranque:

  • Si tu BIOS tiene un menú de arranque rápido, presiona la tecla correspondiente (generalmente F12 o Esc) para acceder directamente al menú de arranque y seleccionar la unidad USB.

Cambiar el Orden de Arranque:

Si necesitas cambiar el orden de arranque:

  • Ve a la sección de arranque o "Boot".
  • Establece la unidad USB como la primera opción.
  • Guarda los cambios y sal del BIOS/UEFI (generalmente con F10).

Arrancar desde el Medio:

  • Después de guardar y salir, la computadora debería reiniciar y cargar desde la unidad USB, iniciando el proceso de instalación de Ubuntu.

Opciones de Particionamiento del disco duro durante la instalación

Durante la instalación de Windows, generalmente se te ofrecen opciones simplificadas de particionamiento, como:

Instalación Normal:

Ubuntu sugiere una configuración automática de particiones. Adecuado si estás instalando Ubuntu como único sistema operativo en el disco.

Personalizado (Avanzado):

Permite configurar particiones manualmente, también puedes crear particiones separadas para / (raíz), /home, y swap (opcional). Útil si deseas una configuración personalizada, como separar el sistema operativo de tus archivos personales.

Configuración de ajustes básicos como idioma, huso horario y teclado

Idioma

  1. Abrir Configuración del Sistema: Ve a "Configuración del Sistema".
  2. Región y Lenguaje: Selecciona esta opción.
  3. Agregar Idioma: Haz clic en el icono + y selecciona el idioma deseado del listado. Aplica y reinicia la sesión para completar la instalación.

Huso Horario

  1. Abrir Configuración del Sistema: Ve a "Configuración del Sistema".
  2. Fecha y Hora: Selecciona esta opción.
  3. Huso Horario: Haz clic en el mapa o selecciona de la lista desplegable el huso horario deseado. Aplica los cambios.

Teclado

  1. Abrir Configuración del Sistema: Ve a "Configuración del Sistema".
  2. Teclado: Selecciona esta opción.
  3. Distribuciones: Ve a la pestaña "Distribuciones", haz clic en "Añadir" y selecciona la distribución de teclado deseada. Aplica los cambios.

Configuración de Ajustes Básicos en Ubuntu Server (Sin Interfaz Gráfica)

Idioma

  1. Conexión SSH: Conéctate al servidor mediante SSH.
  2. Configurar Locales: Ejecuta sudo dpkg-reconfigure locales. Selecciona "es_ES.UTF-8" y establécelo como predeterminado. Reinicia el servidor para aplicar los cambios.

Huso Horario

  1. Conexión SSH: Conéctate al servidor mediante SSH.
  2. Configurar Huso Horario: Ejecuta sudo dpkg-reconfigure tzdata. Selecciona la región y ciudad correspondientes al huso horario deseado. Aplica los cambios.

Teclado

  1. Conexión SSH: Conéctate al servidor mediante SSH.
  2. Configurar Teclado: Ejecuta sudo dpkg-reconfigure keyboard-configuration. Selecciona el modelo de teclado y el idioma "Spanish". Configura las teclas necesarias y reinicia el servidor.

Instalación de drivers necesarios para el funcionamiento del sistema operativo

Actualización del Sistema

Actualiza tu sistema para asegurar que tienes los últimos paquetes y mejoras.

  • sudo apt update
  • sudo apt upgrade

Instalación de Controladores Adicionales

Ve a "Configuración del sistema". Selecciona "Software y actualizaciones". Ve a la pestaña "Controladores adicionales". Selecciona los controladores necesarios y sigue las instrucciones en pantalla.

Reiniciar el Sistema

Reinicia tu computadora para que los nuevos controladores se apliquen correctamente.

  • sudo reboot

Creación de cuentas de usuario y configuración de contraseñas

Añadir y crear usuarios es esencial para los administradores. El comando "useradd" permite crear nuevos usuarios especificando opciones como el directorio de inicio y el shell por defecto. Para una interfaz más interactiva, se puede usar "adduser", que guía al administrador a través del proceso de configuración del usuario, incluyendo la asignación de una contraseña. Tras crear un usuario, el comando "passwd nombre_usuario" se usa para establecer una contraseña segura. Estos pasos aseguran que los usuarios estén configurados correctamente y cumplan con las políticas de seguridad del sistema.

Actualización del sistema operativo después de la instalación

Usando SSH, conéctate a tu servidor:

ssh usuario@direccion_ip

Actualizar la lista de paquetes:

sudo apt update

Actualizar los paquetes instalados:

Actualiza todos los paquetes instalados a sus versiones más recientes:

sudo apt upgrade -y

Actualizar la distribución completa (opcional):

Si quieres actualizar a una nueva versión de Ubuntu Server, puedes hacerlo con:

sudo apt dist-upgrade -y

Eliminar paquetes no necesarios:

Limpia el sistema eliminando paquetes obsoletos y dependencias no utilizadas:

sudo apt autoremove -y

sudo apt autoclean

Reiniciar el servidor (si es necesario):

Después de actualizar, especialmente si el kernel o servicios críticos han sido actualizados, puede ser necesario reiniciar el servidor:

sudo reboot

Configuración de la red y conexión a Internet

    Haz clic sobre el icono de Red en la esquina superior derecha.
  • Selecciona "Configuración de WiFi".
  • Activa el WiFi moviendo el interruptor a la posición "Encendido".
  • Elige tu red inalámbrica de la lista y conéctate ingresando la contraseña si es necesario.

Configuración de opciones de seguridad y privacidad

  • Firewall (UFW): Esencial para controlar el tráfico de red. UFW ofrece una configuración sencilla y efectiva para limitar accesos no autorizados.
  • SELinux: Ofrece un control avanzado sobre los permisos y accesos, ideal para entornos que requieren una seguridad muy rigurosa y granular.
  • Actualizaciones de seguridad: Mantener el sistema actualizado es fundamental para protegerse contra vulnerabilidades conocidas.

Resolución de problemas comunes durante la instalación

    Errores de particionamiento

  • Crear o modificar particiones: Usa GParted para gestionar particiones.
  • "No root file system is defined": Asigna / como punto de montaje durante la instalación.

    • Fallos en la instalación de controladores

  • Controladores de gráficos: Usa el Gestor de controladores o nomodeset en GRUB.

    • Dispositivos de red no funcionan

  • Actualizar kernel: Ejecuta sudo apt update, upgrade, e instala el kernel adecuado.

    • Otros problemas comunes

  • Sistema no arranca: Repara GRUB desde un Live USB.
  • Falta de espacio en disco: Libera espacio con GParted antes de instalar.
  • Instalación se cuelga: Verifica la integridad del medio de instalación y usa opciones de arranque correctas.

Recomendaciones y mejores prácticas para la instalación del Sistema Operativo

  • Verifica Compatibilidad: Asegúrate de que el hardware sea compatible con el sistema operativo.
  • Respaldo de Datos: Haz una copia de seguridad de tus datos importantes antes de instalar.
  • Medio de Instalación Seguro: Usa medios de instalación oficiales y verificados.
  • Particionamiento: Planifica cómo dividir tu disco de manera efectiva.
  • Instala Actualizaciones: Actualiza el sistema y los controladores una vez instalado.
  • Documentación: Registra ajustes y problemas para referencia futura.
