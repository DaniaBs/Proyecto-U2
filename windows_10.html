¿Qué es Windows 10?

Windows 10 es el sistema operativo de Microsoft más usado por los usuarios de ordenadores personales, su lanzamiento fue en julio de 2015 y desde entonces ha recibido muchas actualizaciones para mejorarlo.

Un sistema operativo es el software principal de un ordenador, y como tal es el encargado de gestionar los recursos físicos del ordenador y de la comunicación con los diferentes periféricos de servir de plataforma para ejecutar aplicaciones propias y de terceros.

Windows 10 está más avanzado y adaptador al hardware actual que los anteriores, además posee nuevas funciones que antes eran imposibles de implementar por limitaciones físicas de hardware.

Requisitos del sistema para la instalación del sistema operativo

  • Procesador: Procesador a 1 GHz o más rápido o sistema en un chip (SoC).
  • RAM: 1 GB para 32 bits / 2 GB para 64 bits.
  • Espacio en disco duro: 16 GB para un SO de 32 bits o 32 GB para un SO de 64 bits.
  • Tarjeta gráfica: DirectX 9 o posterior con un controlador WDDM 1.0.
  • Pantalla: 800×600.
  • Conexión a Internet.

Proceso de preparación del medio de instalación (USB, DVD)

Requisitos Previos

  • Unidad USB (8 GB mínimo, se recomiendan 16 GB).
  • Archivo ISO de Windows 10 (Para esto necesitamos descargar Media Creation Tool de Microsoft)

Descargar Media Creation Tool

Crear el medio de instalación:

  • Después de tener el Archivo ISO de Windows mediante Media Creation Tool.
  • Descarga Rufus (es la herramienta que nos servirá para bootear nuestra USB).

Descargar Rufus

  1. Conecta tu USB a la computadora.
  2. Abre la Rufus
  3. Selecciona la imagen ISO que descargaste anteriormente
  4. Selecciona la unidad USB donde deseas crear el booteable y sigue las instrucciones para crear el medio.

Finalización y prueba:

  1. Expulsa la unidad USB de manera segura.
  2. Reinicia la computadora y arranca desde la USB para iniciar la instalación de Windows 10.

Pasos para acceder al menú de arranque y seleccionar el medio de instalación

  • Conecta la unidad USB que contiene el medio de instalación a la computadora.

Entrar al BIOS/UEFI:

  • Reinicia la computadora y presiona repetidamente la tecla Esc, F2, F10, F12 o Del (dependiendo del fabricante de tu computadora) para entrar al BIOS/UEFI.

Menú de Arranque:

  • Si tu BIOS tiene un menú de arranque rápido, presiona la tecla correspondiente (generalmente F12 o Esc) para acceder directamente al menú de arranque y seleccionar la unidad USB.

Cambiar el Orden de Arranque:

Si necesitas cambiar el orden de arranque:

  • Ve a la sección de arranque o "Boot".
  • Establece la unidad USB como la primera opción.
  • Guarda los cambios y sal del BIOS/UEFI (generalmente con F10).

Arrancar desde el Medio:

  • Después de guardar y salir, la computadora debería reiniciar y cargar desde la unidad USB para iniciar la instalación del sistema operativo.

Opciones de Particionamiento del disco duro durante la instalación

Durante la instalación de Windows, generalmente se te ofrecen opciones simplificadas de particionamiento, como:

Partición Única (Simple):

Windows configura automáticamente las particiones necesarias. Esta opción es adecuada si no deseas personalizar el particionamiento.

Personalizado (Avanzado):

Permite crear, eliminar y gestionar particiones manualmente. Útil si deseas dividir el disco en varias particiones o asignar tamaños específicos a cada una.

Configuración de ajustes básicos como idioma, huso horario y teclado

Idioma

  1. Abrir Configuración: Clic en el icono de Windows y luego en la rueda dentada para abrir la configuración.
  2. Hora e Idioma: Selecciona esta categoría.
  3. Idioma: En el menú de la izquierda, selecciona "Idioma". Bajo "Idiomas preferidos", haz clic en "Agregar un idioma preferido", selecciona el idioma deseado y sigue las instrucciones para instalarlo.

Huso Horario

  1. Abrir Configuración: Clic en el icono de Windows y luego en la rueda dentada.
  2. Hora e Idioma: Selecciona esta categoría.
  3. Fecha y Hora: En el menú de la izquierda, selecciona "Fecha y hora". En "Zona horaria", selecciona el huso horario deseado del menú desplegable.

Teclado

  1. Idioma: En el menú de la izquierda, selecciona "Idioma".
  2. Opciones del Idioma: Bajo "Idiomas preferidos", selecciona el idioma predeterminado y haz clic en "Opciones".
  3. Agregar un Teclado: Bajo "Teclados", haz clic en "Agregar un teclado" y selecciona el idioma deseado.

Instalación de drivers necesarios para el funcionamiento del sistema operativo

Crear una carpeta para el controlador:

  • En el escritorio, haz clic derecho y selecciona Nuevo > Carpeta.
  • Nombra la carpeta como "driver".

Copiar y preparar el archivo del controlador:

  • Copia el archivo descargado en la carpeta "driver".
  • Si es un archivo EXE, ejecútalo directamente.
  • Si es un archivo ZIP o RAR, descomprímelo:
  • Haz clic derecho sobre el archivo y selecciona Extraer todo, luego marca Mostrar los archivos extraídos al completar.

Abrir el Administrador de Dispositivos:

  • Ve a Inicio > Panel de Control > Sistema y seguridad > Administrador de dispositivos.

Seleccionar el dispositivo:

  • Encuentra el dispositivo que deseas instalar (ejemplo: adaptador de pantalla).
  • Haz clic en la flecha junto al dispositivo y luego doble clic en el dispositivo específico.

Actualizar el controlador:

  • En las propiedades del dispositivo, selecciona la pestaña Controlador > Actualizar controlador.
  • Elige la opción Buscar software de controlador en el equipo y haz clic en Siguiente.
  • Selecciona Examinar para indicar la carpeta "driver" y haz clic en Siguiente.
  • Escoge el modelo deseado y sigue las instrucciones.

Si no aparece el modelo:

  • Selecciona la opción Elegir en una lista de controladores de dispositivos en el equipo.
  • Haz clic en Usar disco > Examinar y localiza la carpeta "driver".
  • Selecciona el modelo y sigue las instrucciones.

Creación de cuentas de usuario y configuración de contraseñas

  1. Seleccione Inicio > Configuración > Cuentas y, a continuación, seleccione Familia y otros usuarios. (En algunas ediciones de Windows aparecerá Otros usuarios).
  2. Junto a Agregar otro usuario, selecciona Agregar cuenta.
  3. Selecciona No tengo los datos de inicio de sesión de esta persona y, en la página siguiente, selecciona Agregar un usuario sin cuenta Microsoft.
  4. Escribe un nombre de usuario, una contraseña, un indicio de contraseña o elige preguntas de seguridad, y luego selecciona Siguiente.
  5. Abre la configuración y crea otra cuenta.

Actualización del sistema operativo después de la instalación

Cuando la actualización de Windows 10 2022, también conocida como Windows 10, la versión 22H2 esté lista para tu dispositivo, estará disponible para su descarga desde la página de Windows Update en Configuración. Elige una hora adecuada para descargar la actualización. Tendrás entonces que reiniciar el dispositivo y completar la instalación. Después, el dispositivo ejecutará Windows 10, versión 22H2.

Para comprobar si ya estás ejecutando la actualización de Windows 10 2022, seleccione Ver historial de actualizaciones en la página de configuración de Windows Update.

También ten en cuenta lo siguiente:

  • Si quieres instalar la actualización ahora, selecciona Inicio > Configuración > Actualización y seguridad > Windows Update y luego elige Buscar actualizaciones. Si las actualizaciones están disponibles, instálalas.

Buscar actualizaciones

  • Si la versión 22H2 no se ofrece automáticamente a través de Buscar actualizaciones, puedes obtenerla manualmente a través del Asistente de Windows Update.
  • Si tienes problemas con la actualización del dispositivo, incluidos problemas con actualizaciones principales anteriores, consulta las correcciones habituales en Solucionar problemas de actualización de Windows.
  • Si Windows Update te advierte de que no tienes suficiente espacio en el dispositivo para instalar la actualización, consulta Liberar espacio para las actualizaciones de Windows.
  • Si tienes problemas de conexión a Internet durante la actualización del dispositivo, consulta Solucionar Wi-Fi problemas de conexión en Windows.

Configuración de la red y conexión a Internet

Consigue el Equipo Adecuado

Para configurar una red inalámbrica, necesitamos:

  • Conexión a Internet de banda ancha y módem: Contacta con un proveedor de acceso a Internet (ISP) para obtener una conexión ADSL o cable. Los ISP suelen proporcionar el módem necesario, a veces combinado con un router inalámbrico.
  • Enrutador inalámbrico: Permite conectar dispositivos a la red sin cables mediante tecnologías como 802.11a/b/g/n/ac/ax.
  • Adaptador de red inalámbrica: La mayoría de los portátiles y algunas computadoras de escritorio ya vienen con un adaptador de red inalámbrica integrado.

Configurar el Módem y la Conexión a Internet

Sigue las instrucciones del módem para conectarlo a la PC y a la conexión de Internet. Para ADSL, conecta el módem a una toma de teléfono. Para cable, conéctalo a un conector de cable.

Colocación del Router Inalámbrico

Para que la señal sea óptima, sigue estos consejos:

  • Ubicación Central: Coloca el router en el centro de tu casa para aumentar su cobertura.
  • Altura y Obstáculos: Coloca el router lejos del suelo, paredes y objetos metálicos.
  • Interferencias: Minimiza las interferencias evitando equipos que usen la misma frecuencia (2.4 GHz), como microondas y teléfonos inalámbricos. Usa teléfonos inalámbricos de 5.8 GHz para reducir problemas.

Configuración de la Red y Conexión a Internet en Windows 10

  1. Accede a Configuración: Abre el menú de inicio y ve a Configuración > Red e Internet.
  2. Configura la Red: Selecciona Wi-Fi y luego Mostrar redes disponibles. Elige tu red, ingresa la contraseña y conéctate.
  3. Verifica la Conexión: Una vez conectado, verifica que tienes acceso a Internet.

Resolución de problemas comunes durante la instalación

Errores de Particionamiento:

  1. Antes de comenzar la instalación, asegúrate de que el disco duro esté en buen estado y correctamente conectado.
  2. Verifica que no haya particiones corruptas o problemas físicos con el disco.
  3. Durante la instalación, utiliza las opciones de particionamiento del instalador de Windows para crear, formatear o eliminar particiones según sea necesario.

Fallos en la Instalación de Controladores:

  1. Durante la instalación, observa si algún dispositivo muestra un triángulo amarillo con un signo de exclamación en el Administrador de dispositivos de Windows.
  2. Esto indica que puede haber un problema con el controlador del dispositivo.
  3. Para resolverlo, intenta actualizar el controlador desde el Administrador de dispositivos o descargando el controlador más reciente desde el sitio web del fabricante del dispositivo.

Depuración de Instaladores de Clase o Coinstaladores:

  1. Si experimentas problemas con instaladores de clase o coinstaladores durante la instalación de dispositivos, asegúrate de utilizar instaladores compatibles con la versión de Windows que estás instalando.
  2. Verifica los requisitos de compatibilidad del fabricante del hardware o software.
  3. Consulta la documentación o soporte técnico del fabricante para obtener instrucciones específicas sobre cómo depurar problemas durante la instalación.

Documentación de cualquier problema encontrado y las soluciones aplicadas

Identificación del Problema

Localiza y define claramente el problema que afecta los objetivos. Formula preguntas clave para entender dónde, qué, cuándo, quién y por qué ocurre el problema.

Análisis del Problema

Reúne datos e información relevante y confiable sobre el problema. Comprende el problema desglosándolo en segmentos si es complejo. Asigna prioridades basadas en la importancia y urgencia de cada problema identificado.

Generación de Soluciones Potenciales

Propón varias alternativas de solución basadas en los datos y análisis realizados. Considera la condición deseada y las fallas identificadas en el análisis del problema.

Toma de Decisiones y Planes de Acción

Define claramente los problemas. Recopila datos relevantes. Genera opciones viables de solución. Selecciona una acción a seguir. Evalúa los riesgos asociados con cada opción de solución antes de decidir.

Recomendaciones y mejores prácticas para la instalación del Sistema Operativo

  • Verifica Compatibilidad: Asegúrate de que el hardware sea compatible con el sistema operativo.
  • Respaldo de Datos: Haz una copia de seguridad de tus datos importantes antes de instalar.
  • Medio de Instalación Seguro: Usa medios de instalación oficiales y verificados.
  • Particionamiento: Planifica cómo dividir tu disco de manera efectiva.
  • Instala Actualizaciones: Actualiza el sistema y los controladores una vez instalado.
  • Documentación: Registra ajustes y problemas para referencia futura.
